A lightweight, advanced maintenance mode plugin with custom colors, background images, social links, and an AJAX contact form.

== Description ==

Onedev Mode Maintenance Simple is a highly customizable and lightweight plugin that allows you to put your website into maintenance or "coming soon" mode easily. 

Administrators have full access to the site while visitors see a beautiful, responsive maintenance page. It includes zero heavy libraries, ensuring maximum performance and SEO compatibility.

= Features =
* Toggle maintenance mode on and off instantly.
* Fully customizable title, message, and badge.
* Upload a custom logo and background image.
* Select a light or dark theme for the content card.
* Color picker for brand consistency.
* Background overlay opacity control.
* Custom CSS support.
* Integrated lightweight AJAX contact form.
* Social media links (Facebook, Instagram, LinkedIn).
* SEO friendly: Returns HTTP 503 status code.

== Installation ==

1. Upload the `onedev-maintenance-mode` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Navigate to 'Settings > Onedev Maintenance' to configure your page.

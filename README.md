# Onedev Maintenance Mode Simple

Un plugin WordPress léger et performant pour mettre votre site en mode maintenance avec une belle page d'attente personnalisable, tout en gardant l'accès libre pour les administrateurs.

## 🚀 Fonctionnalités

- **Simple et Rapide :** Activation et désactivation en un clic.
- **Personnalisation :** Modifiez le titre, le message d'attente, le texte du badge et ajoutez votre propre logo.
- **Accès Administrateur :** Les utilisateurs ayant les droits d'administration peuvent continuer à naviguer sur le site normalement.
- **SEO Friendly :** Renvoie un code HTTP `503 Service Temporarily Unavailable` pour indiquer aux moteurs de recherche de revenir plus tard sans impacter votre référencement.
- **Compatibilité Cache :** Vidage automatique du cache lors de l'activation/désactivation (Compatible avec LiteSpeed, WP Rocket, WP Super Cache, et W3TC).
- **Sécurité :** Désactivation temporaire des flux RSS (Feed) pendant la maintenance.

## 📋 Prérequis

- **PHP :** 8.1 ou supérieur
- **WordPress :** 6.6 ou supérieur

## ⚙️ Installation

1. Téléchargez le dossier du plugin.
2. Uploadez le dossier `onedev-maintenance-mode` dans le répertoire `/wp-content/plugins/` de votre installation WordPress.
3. Activez le plugin via le menu **Extensions** de WordPress.
4. Rendez-vous dans **Réglages > Onedev Maintenance** pour personnaliser et activer votre page de maintenance.
